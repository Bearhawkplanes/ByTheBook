# Notes for AI assistants

- **Making a checklist from a manual or PDF?** Read `docs/AI-CHECKLIST-GUIDE.md`. It explains the checklist structure and the two formats the app imports (an outline to paste, or a JSON file). You do not need to change the app's code for that.
- **Working on the app's code?** Read `CLAUDE.md` (how the app works, the owner's rules, how to test) and `README.md` (the user manual).
